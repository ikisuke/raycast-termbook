# Termbook for Raycast

Raycastで呼び出す個人用の用語辞書です。用語、読み（別名）、説明、参考URLをMac内のJSONに保存します。通常の検索・編集はローカルで動作し、常駐サーバーは不要です。任意でCodex CLIによる下書き生成を利用できます。画像URLを入力した場合のみ、保存・プレビュー時に画像を取得します。数式・画像の描画にはRaycast標準機能を使います。

## 使い方

Raycastで「辞書を引く」または `jisho` を検索して開きます。

- 入力すると用語、読み、説明を部分一致で絞り込みます。英字の大文字と小文字、全角英数と半角英数、ひらがなとカタカナの違いを吸収します。
- 候補の横に説明を表示します。Enterで数式・画像を含む詳細を開き、⌘Eで編集できます。
- ⌘Nで新しい用語を追加できます。検索結果がないときはEnterでCodexに問い合わせ、⌘Nで手動追加できます。
- 説明と読みは空欄でも保存できます。フォームの⌘Enterで保存します。
- 参考URLは任意で1件登録できます。https:// または http:// から入力してください。詳細のリンクまたは⌘Oで既定のブラウザに開きます。ページの自動取得は行いません。
- ⌘Rで保存済みの辞書を再読み込みできます。
- Raycastの「用語を追加」コマンドから直接登録することもできます。

頻繁に使う場合はRaycast Settings → Extensionsで「辞書を引く」に好みのHotkeyまたはAliasを設定してください。

## 数式・画像・CSV

用語の編集画面に「数式（LaTeX）」と「画像を追加」があります。数式欄には `\frac{a}{b}` や `\sum_{i=1}^{n} x_i` のように数式本体を入力します。Actions →「プレビュー」で保存前に表示を確認できます。検索一覧の右側は数式の組版に対応しないため、保存済みの数式はEnterで開く詳細画面に表示します。TeX文書全体や任意パッケージの追加には対応しません。表示できる構文はRaycast標準の数式機能に従います。

画像はPNG / JPEG / GIF / WebP / SVG、1枚20MB以下。保存時に辞書の保存先へコピーするため、元画像を移動しても残ります。画像URL欄には画像そのもののhttp/https URLを1行に1つ入力します。プレビューまたは保存時に取得し、保存後はURLへアクセスせずローカル画像を表示します。ブラウザのログイン情報は使いません。取得は1枚15秒以内、転送は5回までです。同じフォームでプレビューした画像は保存時にも再利用します。

SVGは外部ファイル参照・スクリプト・アニメーションを含まない静的な図に対応します。非対応の内容や壊れたSVGはエラーで通知します。SVGの変換エンジンは追加せず、Raycast標準の描画を使います。

登録済み画像は通常の編集でも保持されます。検索または詳細のActions →「画像を拡大・管理」（⌘⇧I）で画像一覧を開けます。サムネイルをダブルクリック、または選択してEnterでQuick Lookを開きます。「画像アプリで開く」も選べます。本文中の画像自体はクリック操作を受け付けないため、画像一覧を使います。

画像一覧でActions →「この用語から画像を外す」を選ぶと登録から外れます。同じ画面の「今回外した画像」から戻せます。画面を閉じた後は保存先のimagesフォルダから再添付できます。画像ファイル自体や他の用語の添付は削除しません。

「CSVを取り込む」コマンド、または辞書のActionsから一括追加できます。ファイル選択またはテキスト貼り付け → プレビュー →「新しい用語を追加する」の順です。既存の用語は上書きせずスキップし、CSV内の重複や不正な行はエラーにします。

取り込み形式は以下の独自の2列形式です（一般的なRFC準拠CSVではありません）。

- UTF-8、ヘッダーなし、1行につき `用語,説明`。
- 最初のカンマだけで区切ります。説明中のカンマはそのまま保持します。
- 説明中の文字列 `\n` は改行になります。一般的なCSVの引用符処理は行いません。
- 数式・画像・独立した参考URL欄は、取り込み後に編集画面から追加します。

## ローカル導入・更新

必要環境: macOS、Raycast、Node.js 22.18以上、npm。

リポジトリを取得し、次を実行します。

```sh
git clone https://github.com/ikisuke/raycast-termbook.git
cd raycast-termbook
npm ci --ignore-scripts
npm run dev
```

コマンドがRaycastに登録された後はCtrl+Cで開発プロセスを終了して構いません。拡張は引き続き使えます。ソースを変更したときは、再度 `npm run dev` で反映します。ストア公開やRaycastアカウントによる配布は不要です。

[公式手順](https://developers.raycast.com/basics/create-your-first-extension)

## 保存とバックアップ

保存ファイルはRaycastの拡張専用 `supportPath` 配下の `dictionary.json` です。「辞書を引く」のActionsにある「保存先のパスをコピー」で正確な場所を確認できます。初回の保存時にファイルを作成します。

プレビューだけで取り込んだ画像も `images` フォルダに残る場合があります。

バックアップは `dictionary.json` と隣の `images` フォルダをまとめてコピーしてください。拡張をアンインストールする前にもコピーを残してください。拡張専用フォルダの寿命はRaycast側の管理に従い、アプリや拡張の削除を越えての保持は保証しません。

保存時は最新ファイルを読み直し、一時ファイルへの書き込みを完了してから置き換えます。不正なJSON、未知の形式、重複した用語、古い画面からの編集は保存せずエラーにします。外部エディタとの同時編集は避けてください。

「別の保存処理が進行中」が続く場合、保存中にプロセスが終了してロックが残った可能性があります。Raycastを終了し、保存先のバックアップを取ったうえで、隣の `dictionary.json.lock` ディレクトリだけを取り除き、Raycastを起動してください。`dictionary.json` 自体は削除しません。

### Codexに用語を聞く

検索欄に未登録の用語を入れ、Enterで「Codexに聞いて下書きを作る」を実行します。検索結果がある場合もActionsまたは⌘⇧Aから実行できます。読み・短い日本語説明・必要なLaTeX数式が入力済みのフォームが開くので、確認・修正して保存してください。手動追加は⌘Nです。

Macにインストールしてログイン済みのCodex CLIを使います。問い合わせには通信とCodexの利用枠が必要です。送る入力は検索用語だけで、登録済み辞書は送りません。通常の検索・保存はローカルのままです。CLIのユーザー設定は読み込まず、既存の認証と標準モデルを利用します。下書きは知識ベースの回答で、参考URLを自動捏造しないようURL欄は空欄です。曖昧な用語は「機械学習の○○」など分野を添えられます。Escで中止、2分で時間切れ。失敗画面から再試行できます。

Raycastのトップから専用コマンド「Codexに用語を聞く」も起動できます。用語を入力して⌘Enterで問い合わせます。

### 解説図の自動生成

Codexへの問い合わせでは、用語の仕組みや関係を示す日本語ラベル付きのSVG図も作成し、下書きの画像欄に添付します。⌘⇧P（Actionsの「プレビュー」）で説明・数式・図を確認できます。不要な図は画像欄から外せます。保存後は既存の「画像を拡大・管理」で扱えます。不明な用語で正確な図を作れない場合は添付しません。図の内容も保存前に確認してください。

生成図は保存するまで一時ファイルで、下書きから戻ると破棄されます。保存した図は辞書の画像フォルダへコピーされます。SVGの外部参照や実行要素は既存の検証で拒否します。追加の画像生成APIキーやサーバーは不要です。
